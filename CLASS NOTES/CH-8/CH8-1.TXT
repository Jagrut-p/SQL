SQL> REM SET OPERATORS : TO CLUB/COMBINE TWO RESULT SETS VERTICALLY.
SQL> 
SQL> REM SYNTAX : SELECT ... SET OPERATOR SELECT ... SET OPERATOR SELECT ...
SQL> 
SQL> REM COMPOUND STARTMENT : WHEN WE USE SET OPERATORS TO CLUB TWO RESULT SETS, THE WHOLE STAETMENT IS CALLED COMPOUND STATEMENT.
SQL> 
SQL> REM LIST OF SET OPERATORS : 1 UNION ALL 2 UNION 3 INTERSECT 4 MINUS
SQL> 
SQL> REM RESULT SET : THE COLUMNS AND ROWS WHICH WE GET AS RESULT OF ANY SELECT STATEMENT.
SQL> 
SQL> REM UNION ALL : IT WILL SIMPLY CLUB BOTH THE RESULT SETS VERTICALLY, KEEPING DUPLICATES AS IT IS AND MAINTAINING SAME TOP TO DOWN RANDOM ORDER OF ROWS.
SQL> 
SQL> REM NOTE : REMAINING 3 SET OPERATORS PERFORM TWO COMMON TASKS : 1 REMOVES DUPLICATE 2 SORTS RESULT SET IN ASCENDING ORDER
SQL> 
SQL> REM UNION : IT WILL SIMPLY PERFORM ONLY ABOVE TWO COMMON TASKS.
SQL> 
SQL> REM INTERSECT : IT WILL FIRST SEPARATE COMMON ROWS OF BOTH RESULT SETS AND ON THEM WILL PERFORM ABOVE TWO COMMON TASKS.
SQL> 
SQL> REM MINUS : IT WILL REMOVE COMMON ROWS FROM FIRST RESULT SET AND ON REMAINING ROWS WILL PERFORM ABOVE TWO COMMON TASKS.
SQL>
